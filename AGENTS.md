# Repository guidance

Limitr is a local-first, read-only CLI/TUI for viewing present Codex rate limits across multiple Account Profiles. Read `CONTEXT.md` and the relevant ADRs before changing domain behavior.

## Agent skills

### Issue tracker

Issues and PRDs are tracked in GitHub Issues for `darshmahadevia/limitr`. See `docs/agents/issue-tracker.md`.

### Triage labels

The tracker uses the default Matt Pocock skill label vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository with `CONTEXT.md` at the root and ADRs under `docs/adr/`. See `docs/agents/domain.md`.
