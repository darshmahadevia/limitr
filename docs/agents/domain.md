# Domain Docs

Limitr uses a single domain context.

## Before exploring

- Read `CONTEXT.md`.
- Read ADRs under `docs/adr/` that touch the area being changed.
- Use glossary terms in issue titles, specifications, tests, and user-facing copy.
- Surface any conflict with an ADR instead of silently overriding it.

`CONTEXT.md` is a glossary, not an implementation specification. Create or update ADRs only for decisions that are hard to reverse, surprising without context, and the result of a genuine trade-off.
